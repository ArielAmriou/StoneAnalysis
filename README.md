## Objective

The objective of this project is to analize, crypt and decrypt audio files.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** C++
- **Compilation Manager:** makefile
- **Graphical Library (optional):** SFML

### Linux installation

1. **Clone the repository:**

```sh
git clone git@github.com:ArielAmriou/StoneAnalysis.git
```

2. **Navigate to the project directory:**

```sh
cd StoneAnalysis
```

3. **install dependencies:**

```sh
sudo apt-get install libsfml-dev
```
